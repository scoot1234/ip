# SE-EDU Git Standard

Use the [SE-EDU Git conventions](https://se-education.org/guides/conventions/git.html) for every future commit in this repository.

## Commit messages

- Write an imperative, capitalized subject line with no final period. Aim for 50 characters and never exceed 72 characters.
- Add a focused scope or category prefix when it improves clarity, for example `Parser: Reject missing event descriptions`.
- For non-trivial commits, add a body separated from the subject by a blank line. Wrap body lines at 72 characters, use blank lines between paragraphs, and use bullets where helpful.
- Explain what changed and why it was needed; let the diff explain how.
- If the message becomes long because the change has unrelated concerns, split the work into smaller, cohesive commits.

## Before committing

Review the staged diff, confirm generated files are excluded unless intentionally required, and ensure the commit message follows these rules. Do not commit or push unless explicitly authorized.
